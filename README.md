## 참고

디자인 원본 파일(`.ai`, `.psd`, `.sketch` 등)은 용량이 커서 Git 으로 관리할 때 주의가 필요합니다.
10MB 를 넘는 파일은 Git LFS 사용을 권장합니다.

```
git lfs install
git lfs track "*.ai"
```
